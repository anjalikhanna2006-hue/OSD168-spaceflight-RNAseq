# OSD-168: Spaceflight vs Ground Control, Mouse Liver RNA-seq

Differential expression analysis of NASA GeneLab dataset **OSD-168** (formerly GLDS-168) in R using **DESeq2**.
Done as an assignment during a summer internship at Barcode Biotechnology (June 2026).

## Dataset

- Source: [NASA Open Science Data Repository (OSDR)](https://osdr.nasa.gov), study OSD-168
- Organism / tissue: *Mus musculus* (C57BL/6J), liver
- Platform: RNA-seq (Illumina), ISS mission SpaceX CRS-4 (RR1)
- Groups: Space Flight (FLT), Ground Control (GC), Vivarium Control, Basal Control
- Comparison in this analysis: **Space Flight vs Ground Control** (RR1, with ERCC spike-in, n = 5 per group)

## What the script does

1. Loads the raw count matrix and sample table
2. Filters low-count genes (total count < 10)
3. Normalises and tests differential expression with DESeq2 (Wald test, Benjamini-Hochberg correction)
4. Calls significant genes: adjusted p-value < 0.05 and |log2 fold change| > 1
5. Generates a PCA plot, a volcano plot and a heatmap of the top 40 DEGs

## Results

| | Genes |
|---|---|
| Significant DEGs (padj < 0.05, \|log2FC\| > 1) | 491 |
| Upregulated in spaceflight | 343 |
| Downregulated in spaceflight | 148 |

Upregulated genes included erythropoiesis-related genes (*Hemgn*, *Kel*, *Rhd*, *Epb42*) and the complement gene *Cfd*.
Downregulated genes included the circadian-clock gene *Dbp*.

## How to run

1. Download these files from OSDR (OSD-168) and put them in a folder named `data/` next to the script:
   - `GLDS-168_rna_seq_Unnormalized_Counts.csv`
   - `GLDS-168_rna_seq_SampleTable.csv`
   - `GLDS-168_rna_seq_differential_expression.csv` (optional, only used for gene symbols in plot labels)
2. Open `OSD168_analysis.R` in RStudio
3. `Session > Set Working Directory > To Source File Location`
4. Click **Source**

Outputs are saved in `results/`. Missing packages (DESeq2, EnhancedVolcano, ggplot2, pheatmap) are installed automatically on the first run.
